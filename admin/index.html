깃허브 토큰

이 브라우저에만 저장됩니다

토큰 만드는 방법
  1. GitHub → 프로필 사진 → Settings
  2. 왼쪽 맨 아래 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Token name: jonghyeon-report 발행용
  5. Expiration: 90 days
  6. Resource owner: skantdlv0-cloud
  7. Repository access: Only select repositories → jonghyeon-report 하나만
  8. Permissions → Repository permissions → Contents 를 Read and write
    (Metadata 는 자동으로 켜집니다) 나머지는 전부 No access
  9. Generate token → 이 화면에서 한 번만 보입니다. 복사해서 위에 붙여넣기
